# Power BI Analyst — Desafio DIO

Projeto desenvolvido durante a formação Power BI Analyst da DIO.

## Sobre o projeto

O desafio consiste na reprodução de duas páginas desenvolvidas durante o curso
e na criação de uma terceira página utilizando diferentes visuais no Power BI.

## Terceira página

A terceira página contém:

- Mapa de Sales e unidades vendidas por país;
- Mapa de Profit por país;
- Gráfico de pizza de Profit por segmento.
